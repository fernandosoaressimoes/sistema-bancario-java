# ☕ Meus Estudos em Java - Sistema Bancário via Console

Este é um projeto prático desenvolvido para consolidar meus estudos em **Lógica de Programação** e na linguagem **Java**. O objetivo foi aplicar conceitos fundamentais de desenvolvimento de software em um cenário do mundo real (operações bancárias).

## 🚀 Conceitos Aplicados
* **Estruturas de Repetição (`while`):** Usado para manter o menu ativo até que o usuário decida sair.
* **Estruturas Condicionais (`if/else` e `switch/case`):** Aplicados para validar regras de negócio (como impedir saques maiores que o saldo ou depósitos negativos).
* **Entrada e Saída de Dados (`Scanner`):** Interação em tempo real com o usuário através do terminal/console.
